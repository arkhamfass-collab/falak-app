# الحاسبة الفلكية الشرعية

تطبيق ويب (PWA) لحساب مواقيت الصلاة، وبيانات الشمس والقمر (الإحداثيات البروجية والاستوائية
والأفقية، الشروق والزوال والغروب، الطور، الاقتران القادم...)، والوقت النجمي، باستعمال خوارزميات
جان ميوس (Jean Meeus) ونظرية VSOP87 للشمس.

هذا المستودع يُستضاف مباشرة عبر **GitHub Pages** كصفحة مستقلة (لا كـ Claude Artifact)، وذلك
تحديدا لحل قيدين لا يمكن تجاوزهما من داخل استضافة Claude:

- **تثبيت التطبيق (PWA)** على أندرويد كتطبيق مستقل من الشاشة الرئيسية.
- **تحديد الموقع الجغرافي تلقائيا** عبر صلاحية الموقع في المتصفح.

## التشغيل محليا

لا يحتاج أي خطوة بناء (build) — ملفات HTML/CSS/JS عادية. يكفي تشغيل أي خادم ثابت بسيط من جذر
المجلد، مثلا:

```
python3 -m http.server 8000
```

ثم فتح `http://localhost:8000` في المتصفح.

## البنية

- `index.html` — نقطة الدخول.
- `manifest.webmanifest`, `sw.js` — ملفات PWA (التثبيت والعمل دون اتصال).
- `src/ui/` — الواجهة (الحالة، الأحداث، العرض).
- `src/core/` — محرك الحساب الفلكي (الشمس، القمر، مواقيت الصلاة، التقويم الهجري، الوقت
  النجمي)، بما في ذلك مكتبة `astro/` الفلكية المُضمَّنة (انظر `src/core/astro/LICENSE`
  و`NOTICE.md` لترخيصها الأصلي).
